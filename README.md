# Rainy Days

An online store for rain jackets, built as part of the HTML & CSS and JavaScript 1 courses at Noroff.

## Features

- Responsive design across mobile, tablet and desktop
- Products fetched dynamically from the Noroff API
- Filter by gender and activity type
- Shopping cart with add and remove functionality using localStorage
- Custom toast notifications replacing browser alerts
- Skip-to-content link for keyboard accessibility
- Semantic HTML with aria labels for screen readers

## Getting Started

### Installation

1. Clone the repo:

```bash
git clone https://github.com/DYNNIwav/html-css--Paal-Omland-Eilevstjoenn-.git
```

2. Open `index.html` in your browser or use Live Server in VS Code.

### Running

No build tools or dependencies needed. The project uses plain HTML, CSS and JavaScript.
